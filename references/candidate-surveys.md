# 18个价值目标组卷

候选数据版本为`consolidation-v1`。用户选择的是项目级价值目标；一级维度只用于导航和选择上限，不是统一三因子量表，不替代项目内部的原始维度。

## 选题规则

|选择|未指定题数|指定题数|
|---|---|---|
|一个价值目标|该项目核心＋备份全部候选|从核心＋备份合并池无放回抽取，不区分两库优先级|
|多个价值目标|各项目全部核心候选，不取备份|只从核心池无放回抽取，按目标尽量均衡分配|

多目标总数≤6，同一主归属维度≤3。`--question-count N`指定整份问卷总题数，须为正整数、不超过可用题数；多目标还须不少于目标数，保证每个目标至少1题。超出范围直接返回错误，不自动加题、重复题目或调用备份补足。

多目标均衡分配从每目标0题开始，按用户目标顺序逐轮分配1题，已达到候选容量的目标跳过。余数按目标顺序分配，容量不足的份额转至仍有候选的目标；随后各目标内部等概率无放回抽取。单目标直接在两库合并池等概率抽取。抽到的题仍按项目内原顺序展示，不改题文、选项或审批。抽题默认种子为0，同一数据、目标顺序、题数和种子可复现相同选题；可用`--seed`更换结果。未指定题数时不用抽样，显式种子须与指定题数一起使用。

家国认同3项目、文化涵养9项目、职业素养6项目，完整归属以[维度配置](../data/candidates/dimensions.json)为准。每个项目只有一个主归属；关联维度仅供检索。原始项目编号1—18不等同于交接评审顺序。重复选择同一项目（含名称与别名）会报错，不按题文相似度自动去重。

单目标例子：创造力12题＝6核心＋6备份。多目标例子：创造力＋批判性思维20题＝6核心＋14核心，不加入备份。请求中项目顺序决定组卷顺序，项目内保留交接顺序；编号连续，学生题面不显示项目ID、候选库、风险或一级维度。

## 调用

从实际Skill根目录执行，或用脚本的绝对路径。参数用独立argv传入，不拼接用户自然语言为Shell代码。

```powershell
python -B scripts/candidate_survey.py --list
python -B scripts/candidate_survey.py --goal '创造力' --format wjx
python -B scripts/candidate_survey.py --goal '创造力' --goal '批判性思维' --format chaoxing
python -B scripts/candidate_survey.py --goal '创造力' --question-count 5 --format wjx
python -B scripts/candidate_survey.py --goal '爱国主义态度' --goal '创造力' --goal '学习自我效能感' --question-count 10 --seed 0 --format chaoxing
```

目标可使用准确名称、目录稳定标识或原始编号。可选`--output-dir`、`--request-id`。`survey_export.py`及`teachclaw_entry.py`也接受重复的`--goal`、`--question-count`及`--seed`；单个`--project`配合显式`--format`或`--question-count`进入候选流程。不带新参数的旧`--project/--version`调用仍按原来源版本导出。候选流程不接受A/B卷、原题子集、课程改写等来源版参数，避免静默混用。

TeachClaw新版QQ固定命令默认进入本候选流程，支持多个`--价值目标`、`--题数`、`--格式`与`--种子`；只有显式`--原版`或`--版本`进入旧来源协议。运行部署与验收证据单独记录，具体命令见[TeachClaw接入](teach-claw.md)。

## 两种主文件

- 问卷星：`questionnaire.txt`，首行标题，连续题号，每题`[单选题]`，五个选项各占一行，题间空行。沿用本地单选导入模板；[官方文本导入说明](https://www.wjx.cn/help/help.aspx?helpid=138)的图片细则本次仍无法读取，平台实际导入待核对。
- 学习通：`questionnaire.xls`，真实BIFF8/OLE Excel文件，工作表“课程题库”，20列按[原模板](../assets/importQuestionTemplateNew.xls)顺序，删除说明和样题。每题一行，题型“测评题”，正确答案空，选项数5，M—Q列依次为完全不同意、比较不同意、不确定、比较同意、完全同意。模板A2明确测评题答案可空，B37/G37为对应例子，证据及模板哈希见[模板配置](../assets/chaoxing-template-profile.json)。没有生成正确答案、得分或反向公式。

另附`teacher-notes.md`和`manifest.json`。映射记录可用候选数、指定总题数、实际各目标题数、抽题方法和种子，保留所选项目、一级维度配置、每题导出题号、候选ID、来源与教师事件、原始30字段及题文/分库/合并/计分/量尺五类批准，主文件附SHA256。以返回的`artifacts[].path`交付，不推测文件位置。

## 审查与施测

默认`--purpose review`导出按范围与题数选出的候选集合，保留全部审批与风险状态。当前482题`release_eligible=否`；P0、未分级、暂停/暂缓题与其他题按相同选题规则处理，不因抽中或入核心库而被提升批准。标题标明候选审查稿，教师说明列出状态。

`--purpose survey`逐题检查许可、风险及启用状态，有阻断就不生成任何文件，不静默剔题。当前数据不能生成正式施测文件。尤其科研诚信RI-L001—RI-L016的统一同意稿与历史F1/F2双量尺冲突仍待教师决定。不同项目不可自动同向合分或解释成同一总分，量尺改编不推定等值。

两种文件均须在目标平台实际导入核对。Excel引擎读取成功与本地结构测试，不代表学习通平台已导入通过；旧来源版的问卷星反馈也不扩张到本候选库。

## 维护

导入工具`import_candidate_handoff.py`核验ZIP清单哈希后保留数据原字节，不执行包中脚本；不同内容不覆盖。`candidate_data.py validate`检查482/505关系、23个双来源候选、原始字段及独立批准。正常运行只需Python标准库和本目录资源，不需要模型服务或网络。
